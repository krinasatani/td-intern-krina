# Chapter 03 – Top 10 Git Commands

1. `git init` – Initializes a new Git repository.
2. `git clone` – Copies a remote repository to your computer.
3. `git status` – Shows the current working tree status.
4. `git add` – Stages changes for the next commit.
5. `git commit` – Saves staged changes as a commit.
6. `git branch` – Lists or creates branches.
7. `git switch` – Switches between branches.
8. `git push` – Uploads local commits to a remote repository.
9. `git pull` – Fetches and integrates remote changes.
10. `git log` – Displays commit history.
